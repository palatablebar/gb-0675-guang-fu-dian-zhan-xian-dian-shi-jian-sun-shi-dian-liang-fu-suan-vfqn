# 功率与限电定义

设备额定功率为kW。遥测kW与MW统一为kW，辐照度为W/m²。样本时刻须带偏移，统一UTC。记录代表自采样时刻起600秒的左值保持区间，超过600秒不外推，缺测保持未定。
每台设备重叠或相邻限电事件先求并集，再按遥测及有效期边界切分半开区间。样例INV-A的10:00–10:20及10:10–10:30合并为30分钟，不能重复积分重叠10分钟。
基线只采用同区域、同采样时刻、同100W/m²辐照档、健康且不处于限电中的参考逆变器；至少2台。对参考功率按各自额定功率归一，取中位数再乘目标额定功率，基线不超过目标额定功率。无合格对照返回NO_REFERENCE及null损失，不填0。
温度列为可选证据列（°C），只用于所在遥测样本的片段，有效期同功率（600秒左值保持）。温度修正按片段进行：excess=max(0,T−参考温度)，系数=clamp(1−每℃系数×excess,0,1)，修正基线=基线×系数；参考温度默认25°C、每℃系数默认0.004，可用 `temperature_correction` 覆盖。日最高温统一扣减只作建议值，全部片段待查。温度证据缺失、越界或未覆盖片段时该片段未定，不回退未修正基线，不填0。修正后未修正基线与修正基线、温度扣减满足 raw=adjusted+adjust。无温度列的批次不启用温度修正，行为与原先一致。
每片段损失=max(修正基线−实际,0)×秒数/3600。实际高于基线时损失0。计算保留Decimal精度，汇总后统一保留0.0001kWh；未定时长单独展示，不并入已确定损失。
清批INV-A基线100kW、实际60kW、并集30分钟，损失20kWh；INV-B基线50、实际30、20分钟，损失6.6667kWh。总确定损失26.6667kWh。高温批 heat.csv：35°C片段基线100→96、损失6.0000kWh；55°C片段100→88、损失4.6667kWh；缺温度片段待查；确定损失16.0000kWh，温度扣减4.0000kWh。能量核验按实际+非负损失计算可解释基准电量。
同设备同一时刻不同观测全部隔离；同值重复观测保留稳定编号。封存需无隔离和未定片段。此工具供离线复算，不包含生产控制或电网调度。
